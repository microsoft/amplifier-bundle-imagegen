# Imagegen capability bundle

Own the portable image capability, its module, skill, context and composition.
Keep application setup, UI/artifact presentation and live account qualification in
the consuming host. Runtime code must not depend on or name consuming applications.
Preserve explicit backend selection, provider neutrality, durable request identity,
unknown-effect handling and original artifacts. Do not add implicit paid fallback.

Keep mutable Amplifier Git sources at canonical Microsoft `@main`. Record exact
resolved revisions as validation evidence, not manifest pins. Use isolated caches
and environments. Offline tests must block real network requests and qualify the
real Foundation/Core subdirectory source loader without skipping it. Do not treat
ported live results as new repository, account or host acceptance.

Preserve upstream provenance and notices. Follow
https://github.com/microsoft/amplifier/blob/main/docs/REPOSITORY_RULES.md.
